# 🍫 Cocoa Bliss — Premium Chocolate Experience

**Cocoa Bliss** is a premium chocolate brand website designed to deliver an elegant, modern, and delightful online experience. The website combines attractive visuals, a refined user interface, and a smooth browsing experience to showcase the brand's chocolate products and identity.

The project focuses on presenting chocolate as more than a treat — as a personalized experience designed for gifting, celebrations, and memorable moments.

## ✨ Features

* **Premium UI Design** — A modern and visually appealing interface reflecting the brand's premium identity.
* **Responsive Layout** — Designed to provide a consistent browsing experience across different screen sizes.
* **Product Showcase** — Presenting chocolate products through an engaging visual layout.
* **Brand Storytelling** — Communicating the brand's identity, values, and premium chocolate experience.
* **Interactive User Interface** — Smooth navigation and engaging frontend interactions.
* **Customer-Focused Experience** — Designed to make exploring the brand simple and enjoyable.

## 🛠️ Tech Stack

* **React** — Component-based user interface development.
* **TypeScript** — Type-safe JavaScript development.
* **Vite** — Fast development server and frontend build tooling.
* **CSS** — Styling and responsive layouts.
* **npm** — Package management and development scripts.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install the following tools:

* [Node.js](https://nodejs.org/)
* npm (included with Node.js)
* [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone <your-repository-url>
```

**2. Navigate to the project directory**

```bash
cd cocoabliss
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

### Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
